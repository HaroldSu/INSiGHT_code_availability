This repository contains the R code used to reproduce the simulation and real-data analysis results presented in the original [INSiGHT](https://github.com/Cui-STT-Lab/INSiGHT) paper.

Specifically:

- The `Simulations` folder contains the R scripts used for the simulation studies associated with Figs. 2 and 3 and Supplementary Figs. S1–S4.
- The `DLPFC` folder contains the R scripts for the analysis of the 10x Genomics human dorsolateral prefrontal cortex ([DLPFC](https://doi.org/10.1038/s41593-020-00787-0)) spatial transcriptomics dataset associated with Fig. 4.
- The `PDAC` folder contains the R scripts for the analysis of the 10x Genomics Visium human pancreatic ductal adenocarcinoma ([PDAC](https://doi.org/10.1158/1078-0432.CCR-24-2183)) spatial transcriptomics dataset associated with Fig. 5.
- The `AD` folder contains the R scripts for the analysis of the 10x Genomics Visium spatial transcriptomics dataset from Alzheimer's disease ([AD](https://doi.org/10.1038/s41588-024-01961-x)) samples associated with Fig. 6.
